# 聽文件 · 文件朗讀器

把 PDF 或 Word 丟進去，手機就會讀給你聽。支援**中文、英文、日文、希臘文、拉丁文、希伯來文**六種語言，彼此可以互相翻譯，翻完直接用該語言的聲音唸出來。

整個 App 是**一個網頁**，放在 GitHub Pages 上就能在 iPhone 和 Android 使用，不用送審、不用 App Store、不用付錢。

---

## 功能對照

| 你要的 | 做法 |
|---|---|
| 上傳 PDF / Word 轉語音 | 支援 `.pdf`、`.docx`、`.txt`、`.md`。用手機系統內建的語音引擎朗讀 |
| 記住每次上傳的檔案 | 文字內容存在手機的 IndexedDB，關掉重開、隔天再打開都還在 |
| 1× / 1.5× / 2× 語速 | 播放列右邊按一下循環：0.75 / 1 / 1.25 / 1.5 / 2，播放中改也會立刻生效 |
| 六種語言 | 中文、英文、日文、希臘文（含古希臘多調符號）、拉丁文、希伯來文。自動判斷整份文件語言，**再逐句判斷**，夾雜的文件會自動換聲音。希伯來文會由右至左顯示 |
| 六種語言互譯再讀 | 閱讀器上方橫向捲動選「中文 / English / 日本語 / Ελληνικά / Latina / עברית」，翻完用**該語言的聲音**唸出來。各語言譯文分別存起來，同一份文件同一個語言只翻一次 |
| 收藏 | 每份文件的 ☆，書櫃上有「收藏」分頁 |
| 閱讀紀錄 | 記住讀到第幾句、進度百分比、累計已聽時間、最後閱讀時間 |
| 停止 / 暫停 / 閱讀 | 底部固定播放列，另有上一句與可拖曳的進度條，點任一句可跳過去讀 |
| 重點整理 + 逐字稿 | 閱讀器上方「📝 重點整理」，自動挑出全文重點句、關鍵詞、章節標題，連同全文逐字稿存成 `.txt` |
| 關螢幕繼續聽 | 切到「🎧 背景播放」模式，鎖屏、切到別的 App 都會繼續唸，鎖定畫面還有控制按鈕 |

## 上架步驟（不用裝任何開發工具，用手機或電腦的瀏覽器就能做完）

### 1. 建一個 GitHub repository
1. 到 <https://github.com/new>
2. Repository name 填 `doc-reader`（名字隨你）
3. 選 **Public**（Public 才能免費用 GitHub Pages）
4. 按 **Create repository**

### 2. 把這 5 個檔案上傳
在新建好的 repo 頁面點 **Add file → Upload files**，把下面這些檔案一起拖進去，然後按 **Commit changes**：

```
index.html
manifest.json
sw.js
icon-192.png
icon-512.png
```

> 這五個檔案必須放在**同一層**（repository 的根目錄），不要包一層資料夾。

### 3. 打開 GitHub Pages
1. repo 上方 **Settings**
2. 左邊選 **Pages**
3. Source 選 **Deploy from a branch**
4. Branch 選 **main**、資料夾選 **/ (root)**，按 **Save**
5. 等 1～2 分鐘，頁面上方會出現網址：

```
https://你的帳號.github.io/doc-reader/
```

### 4. 裝到手機上

**iPhone（一定要用 Safari）**
1. Safari 開上面那個網址
2. 下方「分享」按鈕 → **加入主畫面**
3. 主畫面就會出現「聽文件」的圖示，打開後沒有網址列，跟一般 App 一樣

**Android（Chrome）**
1. Chrome 開網址
2. 右上角「⋮」→ **安裝應用程式**／**加到主畫面**

## 使用上一定要知道的幾件事

**iPhone 的靜音實體開關**
側邊的靜音鍵如果撥到靜音，網頁語音可能不出聲。沒聲音時先檢查這個。

**兩種朗讀方式，螢幕關掉要用「背景播放」**

閱讀器上方有一顆按鈕可以切換：

| | 🔊 裝置語音（預設） | 🎧 背景播放 |
|---|---|---|
| 螢幕關掉 | **會停** | **繼續唸** |
| 網路 | 不用，完全離線 | 每一句都要連網抓音訊 |
| 鎖定畫面控制 | 無 | 有，可在鎖定畫面／耳機按鈕控制播放、上下句 |
| 聲音 | 手機內建語音，可自己挑 | 由翻譯服務提供，不能挑 |
| 拉丁文 | 沒有語音，用義大利文近似 | 有拉丁文發音 |

原因是手機瀏覽器的「語音合成」被系統設計成螢幕一鎖就中斷，這點網頁 App 繞不過去；但**音訊播放**不會被中斷（跟聽 podcast 一樣）。所以背景播放模式是把每一句轉成 MP3，用一般播放器播出來。

想睡前聽、或邊走邊聽不看螢幕，就切到「🎧 背景播放」。要在飛機上或沒訊號的地方聽，就用「🔊 裝置語音」。

另外設定裡有「播放時不讓螢幕自動關閉」，預設開啟，用裝置語音時可以避免讀到一半被鎖屏打斷。

背景播放如果連續失敗（沒網路、服務被限流），App 會自動退回裝置語音並提示你，不會卡住。

**重點整理是怎麼整理的**

點閱讀器上方的「📝 重點整理」，選好比例按「產生」，會得到一份文字檔，內容依序是：

```
標題、來源檔名、字數句數、預估朗讀時間
──── 關鍵詞 ────         全文最具代表性的用詞（中日文會把雙字詞接回完整詞彙）
──── 可能的章節標題 ──── 偵測出的短標題行
──── 重點摘要 ────       依原文順序排好的重點句，可選 8% / 15% / 25% / 40%
──── 全文逐字稿 ────     每句加上編號，方便引用；有譯文時可選擇附上對照
```

做法是統計全文用詞、算出每一句的資訊量，挑出最有代表性的句子。**它挑的是原文既有的句子，不會改寫、不會自己生成內容**，所以不會有 AI 編造的風險，缺點是讀起來比較像「畫重點」而不是「寫摘要」。整個計算在手機裡完成，不需網路、文件不外流。

如果當下看的是譯文（例如日文文件翻成中文），整理出來的就是中文版的重點，逐字稿也可以選擇附上原文對照——拿來讀外語文獻很好用。

**下載的 txt 存到哪裡**
iPhone 會跳出系統分享選單，選「儲存到檔案」即可；Android 直接下載到「下載」資料夾。檔案有加 UTF-8 BOM，用 Windows 記事本開也不會變亂碼。

**拉丁文沒有語音，這是全世界手機共通的限制**
iPhone、Android 都沒有拉丁文的文字轉語音。這個 App 會自動改用**義大利文**語音來唸拉丁文——義大利文的發音規則最接近教會拉丁文，古典學界也常這樣處理。你也可以在「語音設定 › 拉丁文」改成西班牙文或羅馬尼亞文的聲音試試。

**拉丁文文件要手動指定語言**
拉丁文和英文都用拉丁字母，程式無法自動分辨，會先當成英文。開啟文件後點「語音設定」，最下面的「這份文件的原文語言」選「拉丁文」，整份就會改用拉丁文處理（希臘文、希伯來文因為字母不同，可以自動判斷，不用設定）。

**希臘文、希伯來文的語音要先下載**
iPhone：設定 › 輔助使用 › 朗讀內容 › 聲音 › 找 Ελληνικά（Melina）和 עברית（Carmit）下載。
Android：Google 文字轉語音的語音資料裡安裝希臘文、希伯來文。沒裝的話 App 會跳出提醒。

**讓聲音更好聽**
iPhone：設定 › 輔助使用 › 朗讀內容 › 聲音 › 中文／日文 › 下載「加強版」或「Siri」語音。下載完回到 App，在「語音設定」裡就選得到。
Android：設定 › 系統 › 語言與輸入 › 文字轉語音輸出，安裝 Google 文字轉語音的中文與日文語音包。

**掃描檔（圖片型 PDF）讀不出來**
如果 PDF 是用掃描器掃的，裡面沒有文字層，App 會提示「抓不到文字」。要先用其他工具做 OCR 轉成可選取文字的 PDF。

**舊版 `.doc`**
只支援 `.docx`。舊的 `.doc` 請先用 Word 另存成 `.docx` 或 PDF。

**翻譯需要網路**
翻譯用的是免費公開的翻譯端點（Google `translate_a` 為主，MyMemory 為備援），沒有金鑰、也不保證永遠可用。長文件會分批送出，翻完會存在手機裡，同一份文件翻成同一個語言只會做一次。三種譯文可以同時保存，隨時切換。如果之後想換成穩定的付費服務，改 `index.html` 裡的 `translateOne()` 這個函式就好，其他都不用動。

**檔案不會外流**
文件解析、朗讀、儲存全部在手機本機完成，沒有任何伺服器。唯一對外的連線是按下「翻成中文」的時候。也因為都在本機，換手機或清除瀏覽器資料，書櫃會跟著不見。

## 想改東西的話

全部邏輯都在 `index.html` 一個檔案裡，用註解分成十三段：

| 段落 | 內容 |
|---|---|
| 一 | PDF / Word 解析 |
| 二 | 切句與六語判斷 |
| 三 | 語音挑選 |
| 四 | 播放引擎（播放／暫停／停止／跳句） |
| 五 | 翻譯 |
| 六 | 匯入檔案 |
| 七～八 | 書櫃與閱讀器畫面 |
| 九～十一 | 播放列、原文／六語翻譯切換、設定 |
| 十四 | 重點抽取、關鍵詞、逐字稿與 txt 匯出 |
| 十二～十三 | 檔案輸入、儲存與啟動 |

常見小調整：
- 句子太長被截斷 → 改最上面的 `MAXLEN`（預設 150）
- 想加 3× 語速 → 改 `RATES` 陣列
- 想翻成簡體 → 把 `GTX_CODE` 裡的 `zh:'zh-TW'` 改成 `zh:'zh-CN'`
- 想多加一種語言（例如韓文）→ 在 `LANGS`、`LANG_CODE`、`LANG_NAME`、`VOICE_PREFS`、`VOICE_FILTER`、`GTX_CODE`、`MM_CODE`、`CHIP_LABEL` 各加一行，再複製一顆 `.chip.tl` 按鈕和一個語音下拉選單
- 覺得摘要挑得不準 → 調 `summarize()` 裡的權重（開頭加分、數字加分、短句扣分）
- 想改成用 AI 產生真正的摘要 → 在 `buildReport()` 裡把 `summarize()` 換成呼叫你自己的 API
- 背景播放想換成自己的語音服務（Google Cloud TTS、ElevenLabs 等）→ 只改 `ttsUrl()` 這個函式，讓它回傳一個音訊網址就好
- 改版後想讓手機拿到新版 → 把 `sw.js` 裡的 `VERSION` 數字 +1

改完在 GitHub 網頁上直接編輯檔案並 commit，一分鐘後手機重新整理就是新版。
